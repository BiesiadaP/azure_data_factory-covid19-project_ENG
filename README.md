# Azure Data Factory COVID-19 Project

## Project Overview
This project utilizes Azure Data Factory to process and analyze COVID-19 data from various sources, focusing on the European context. The aim is to create a robust data pipeline that can ingest, transform, and load COVID-19 datasets for reporting and visualization.

## Tools Used
- **Azure Data Factory**: The main tool responsible for orchestrating data movement and transformation.
- **Azure Data Lake Storage**: Used for storing raw and processed data.
- **Azure SQL Database**: Used for hosting the processed datasets that are queryable.
- **Power BI**: For data visualization and creating dashboards to present insights derived from the data.

## Data Sources
The project aggregates COVID-19 data from multiple trusted sources, including:
- **European Centre for Disease Prevention and Control (ECDC)**: The primary source for COVID-19 statistics across Europe.
- **World Health Organization (WHO)**: Provides international data that complements our European focus.
- **National Health Services**: Data from individual countries to provide localized insights.

## Focus on European COVID-19 Data
This project specifically targets the European COVID-19 situation, allowing stakeholders to better understand trends, inception rates, and recovery statistics. By analyzing this data, we aim to support public health initiatives and decision-making processes within Europe.

## Conclusion
Through this Azure Data Factory COVID-19 project, we aim to deliver timely and relevant insights into the COVID-19 pandemic, specifically tailored to regional requirements and policies.
