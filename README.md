# Azure Data Factory Covid-19 Project

This project utilizes Azure Data Factory for processing and analyzing COVID-19 data.

## Azure DevOps

We are using Azure DevOps to manage our development, testing, and production environments. This setup ensures that our workflow is efficient and effective, allowing for clear visibility and management of the entire process. 

## CI/CD Release Process

The project includes an automated CI/CD release process, enabling seamless integration and delivery. After code is pushed to the repository, automated tests are run, and if successful, the code is automatically deployed to the respective environment. This process ensures that only quality code is moved to production, minimizing risks and enhancing our deployment frequency.
